# Understand the Data

Sebelum menghitung, baca data dictionary dan periksa grain. Dataset transactions menyimpan satu baris untuk satu order-item transaction. Satu order dapat muncul beberapa kali karena berisi beberapa product.

Untuk project ini, hubungan ke products membantu membaca category, tetapi jangan menghitung jumlah order dengan menghitung jumlah baris transaction.

Catat juga batas data: periode hanya Agustus dan September 2025. Temuanmu akan menjelaskan dua bulan ini, bukan tren tahunan.
